# ВК-бот для поиска фильмов (CinemaBot)

Учебный проект на языке Python для поиска информации о фильмах через API Кинопоиска и интеграции с сообществом ВКонтакте.

## Функционал
- **Поиск по названию**: просто отправьте сообщение с названием фильма.
- **Случайный фильм**: выдает случайную картину с рейтингом и постером.
- **ТОП по годам**: фильтрация лучших фильмов за конкретный выбранный год.
- **История запросов**: просмотр последних 5 запросов пользователя (хранится в SQLite через Peewee ORM).

## Команды
- `/help` — получение справки.
- `/history` — вывод истории запросов.
- Кнопки интерфейса для поиска и фильтрации.

## Установка и запуск

1. Клонируйте репозиторий.
2. Создайте файл `.env` в корневой папке и добавьте туда ваши токены:
   ```env
   VK_TOKEN=ваш_токен_вк
   KP_TOKEN=ваш_api_ключ_кинопоиска
   ```
3. Установите необходимые библиотеки:
   ```bash
   pip install -r requirements.txt
   ```
4. Запустите бота из терминала:
   ```bash
   python main.py
   ```

## Технологии
- Python 3.x
- VK API (vk_api)
- Kinopoisk API (через requests)
- База данных: SQLite
- ORM: Peewee
